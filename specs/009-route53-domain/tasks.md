- [x] T005 [Stage 1: Platform] In `terraform/environments/dev/main.tf`: extend `null_resource.apply_app_frontend_ingress` `depends_on` from `[null_resource.apply_app_backend]` to `[null_resource.apply_app_backend, null_resource.apply_cert_manager]` so the Ingress `tls` + Certificate apply only after the issuers exist. **Do NOT add `apply_route53_record`** — it would create a cycle (`apply_route53_record` → `apply_aws_ccm` → `apply_app_frontend_ingress`, since the CCM already depends on the ingress to annotate its Service). The Certificate self-heals via cert-manager's automatic HTTP-01 retry once the ALIAS record is live (Depends on T003)
